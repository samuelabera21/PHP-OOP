# Concept 1: What is OOP?

Object-Oriented Programming (OOP) is a way of writing programs using **objects**.

## Exact core idea
- An object represents a real-world entity.
- Each object has:
  - **Data** (called properties/attributes)
  - **Behavior** (called methods/functions)

## Quick exam points
- OOP makes code easier to organize, reuse, and maintain.
- A class is a blueprint.
- An object is a real instance created from that blueprint.

## In one sentence
OOP models real things in code by combining data and actions inside objects.
